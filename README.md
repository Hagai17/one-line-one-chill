# One Line, One Chill

A make.fun entry for [One Line, One Chill](https://make.fun/bounties/u-azazex-one-line-one-chill-6d4d5488?utm_source=github&utm_medium=readme&utm_campaign=one-line-one-chill): the single scariest sentence I could write, under 200 characters.

**The entry:**

> Someone keeps returning my spare key through the letterbox, polished clean, though I have never lent it to anyone; last night it came back warm.

## Run it

```sh
python3 main.py
```

The program prints the entry and writes it to `/output/entry.txt`, where the competition harness reads it. The full draft set and the head-to-head duel scoring that picked this line are in `candidates.md`.
